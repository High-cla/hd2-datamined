# 近炸引信：字段在弹丸行上（build `26088801`）

> **一句话**：近炸引信就在**弹丸行**（`ProjectileSettings`，272 B）里 ——
> **`+0x94` = 近炸半径（米）**，配 `+0x88` 阈值角、`+0xA0` 保险距离、`+0x98` 延迟。
> 值 0 = 没有近炸。AC-8 的近炸**不在主弹**上，而在它的**破片备弹 289** 上（`fnid=8` 可编程弹药切换）。

## 0. 验证状态

| 结论 | 状态 | 依据 |
|---|---|---|
| 近炸字段在弹丸行 `+0x88 ~ +0xA0` 这一段 | **✓ 离线** | 外部结构（filediver `rawProjectileInfo`）+ 本 build 全表数据对照，两者独立吻合 |
| `+0x94` f32 = **近炸半径（米）** | **✓ 离线（强）** | 全表 355 行里只有 28 行非零；两把已知有近炸的武器弹丸都非零且数值合理（2 m / 3 m）；负对照（MG-43 / EAT-17 / Spear）全 0 |
| `+0x88` f32 = 爆炸**阈值角**（度） | **✓ 离线** | RL-77 = **360°**（全向触发 = 空炸）；AC-8 破片 = 90°；普通武器 60–80° |
| `+0xA0` f32 = **保险距离（米）** | **✓ 离线** | AC-8 破片 8 m、RL-77 1 m、GL-21 7 m；无引信武器为 0 |
| `+0x98` f32 = 爆炸**延迟（秒）** | **✓ 离线** | RL-77 = 0.2 s（空炸后延迟爆），其余多为 0 |
| `+0x90` / `+0x9C` u32 = **撞击时 / 失效时**的爆炸类型 id | **✓ 离线** | RL-77 两者都是 325；AC-8 主弹 406、破片 381 |
| AC-8 的近炸在**备弹 289** 上，不在主弹 117 | **✓ 离线** | fire 行 247：`+0`=117、`+576`=**289**；且 WeaponData `+184 fnid=8`（可编程弹药） |
| 改 `+0x94` 会让普通弹丸获得近炸 | **⚠ 未实机** | 按 README 的三态口径，这条仍待上机 |

## 1. 弹丸行里的引信段（272 B 行）

| 偏移 | 类型 | 字段（外部结构名） | 含义 |
|---|---|---|---|
| `+0x88` | f32 | `ExplosionThresholdAngle` | 触发所需的最小入射角；**360 = 全向**（空炸） |
| `+0x8C` | u32 | `UnkBool` + 3 B 填充 | 未解，本 build 多为 0 |
| `+0x90` | u32 | `ExplosionTypeOnImpact` | **撞击时**产生的爆炸类型 id（0 = 无） |
| **`+0x94`** | **f32** | **`ExplosionProximity`** | **近炸半径（米）** ← 近炸引信的主开关 |
| `+0x98` | f32 | `ExplosionDelay` | 触发到爆炸的延迟（秒） |
| `+0x9C` | u32 | `ExplosionTypeExpire` | **失效时**（寿命到了）产生的爆炸类型 id |
| `+0xA0` | f32 | `ArmingDistance` | **保险距离（米）** —— 出膛后多少米内不触发 |

## 2. 本 build 实测数据（六把对照）

| 弹丸 | 阈值角 | 撞击爆 | **近炸半径** | 延迟 | 失效爆 | 保险距离 |
|---|---:|---:|---:|---:|---:|---:|
| AC-8 主弹 `117` | 60° | 406 | **0** | 0 | 0 | 0 |
| **AC-8 破片备弹 `289`** | 90° | 381 | **3 m** | 0 | 0 | 8 m |
| **RL-77 主弹 `317`** | **360°** | 325 | **2 m** | **0.2 s** | 325 | 1 m |
| RL-77 备弹 `98` | 360° | 300 | 0 | 0.2 | 300 | 1 m |
| MG-43 `150` | 80° | 0 | 0 | 0 | 0 | 0 |
| EAT-17 `134` | 60° | 377 | 0 | 0 | 0 | 0 |
| GL-21 `285` | 80° | 362 | 0 | 0 | 362 | 7 m |
| Spear `229` | 80° | 304 | 0 | 0 | 0 | 0 |

**判据**：`+0x94` 在 355 行里只有 28 行非零，且「已知有近炸的两把」都在其中、数值落在 2–3 m 的合理区间；
负对照全部为 0。⇒ 这不是巧合，是字段。

## 3. AC-8 为什么要找备弹

AC-8 在游戏里能打**破片弹**，那不是它主弹的行为：

| 项 | 值 |
|---|---|
| fire 行 | 247 |
| `+0` 主弹 | `117`（阈值 60°、近炸 0、保险 0） |
| **`+576` 备弹** | **`289`（阈值 90°、近炸 3 m、保险 8 m）** |
| WeaponData `+184` | **`fnid = 8`** = 引擎原生 ProgrammableAmmo（可编程弹药切换） |

⇒ 改主弹 `117` 的 `+0x94` 得到的是「AP 弹也带近炸」；
要让破片弹变化，改的是 `289`。

## 4. 怎么改 / 怎么验

```bash
# 例：给 AC-8 主弹（117）加 3 m 近炸
python tools/entity_field_set.py set --block 0xBD4042C2 \
    --key 0x00000075 --field 0x94 --type f32 --value 3.0 --expect-old 0 --out proj.plain
# ⚠ 弹丸表是「计长数组」不是哈希表，行靠 id 定位；用 pod_loadout/自写脚本时注意这一点
```

上机判读：打到敌人附近（不命中）会不会提前炸；`+0x94` 写 0 → 恢复直击。

**未做**：本 build 还没实机验证过「给无引信弹丸加近炸」。要验的话，
最干净的单变量实验是给 **MG-43 的 `150`** 写 `+0x94 = 3.0`，看它是否在敌人附近空炸。

## 5. 边界

- 近炸**依赖 `+0x90` 指向一个真实存在的爆炸类型**；只填半径、撞击爆炸为 0 的弹丸，近炸触发后可能什么都不发生。
- `+0x88` 阈值角是**几何门槛**：360° 表示任何角度都算「接近」，普通武器是 60–80°（要求接近垂直入射）。
- 这两个是**弹丸级**字段：同一弹丸被多把武器共用时一起变（改前先查引用，工具见 `dmg_refs.py` / `pod_loadout.py` 的同类做法）。

## 6. 溯源

字段名与结构顺序来自 **filediver** 的 `projectile_settings.go`（`rawProjectileInfo`），
本仓库只取**名称与相对顺序**，偏移全部用本 build 的数据对照独立确认
（外部结构累计有 5 B 误差，因此**没有直接采用它的绝对偏移**）。
数值、弹药归属（AC-8 `fnid=8` + 备弹 289）为本 build 自行读取。
